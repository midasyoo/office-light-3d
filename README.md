# 사무실 3D 조명 제어

파티션으로 나뉜 사무실을 3D로 보면서, 좌석별·구역별로 조명을 켜고 끄는 시뮬레이터.

> **바로 열기** — <https://midasyoo.github.io/office-light-3d/>
> 설치할 것도, 서버도 필요 없습니다. 파일 하나만 내려받아 더블클릭해도 됩니다.

## 무엇을 하나

- **조명 30개**를 하나씩 또는 블록·전체 단위로 켜고 끈다
- 조명을 끄면 그 구역 사람들이 **일어나 통로로 나가 퇴근**한다
- 좌석을 클릭하면 그 자리를 담당하는 조명이 반응한다
- 탑뷰 / 조감뷰 / 시점뷰 전환, 천장 표시, 이름표 표시

72석 · 조명 30개 · 7개 구역으로 구성된 실제 규모의 사무실 배치를 씁니다.

## 내 사무실처럼 쓰기

좌측 **좌석 설정**에서 자리에 이름과 얼굴을 넣을 수 있습니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 이름 바꾸기 | 좌석 클릭 → `좌석 이름`에 입력 → **변경** (Enter도 됨) |
| 사진 넣기 | **사진 추가**로 이미지 선택 → 좌석 클릭 → 목록에서 사진 클릭 |
| 배정 해제 | 좌석 클릭 → **배정 해제** |
| 처음으로 되돌리기 | **전체 초기화** |

> **올린 사진과 바꾼 이름은 이 브라우저 안에만 저장됩니다.**
> 서버로 전송하지 않고, 전송할 곳도 없습니다 — 이 사이트는 정적 파일뿐입니다.
> 사진은 160×160으로 줄여 저장하며 원본은 남기지 않습니다.
> 다른 기기에서는 보이지 않고, 브라우저 데이터를 지우면 함께 사라집니다.

## 실행 방법

| 방법 | 절차 |
|---|---|
| 웹 | <https://midasyoo.github.io/office-light-3d/> |
| 앱으로 설치 | 위 주소를 연 뒤 설치 (아래 참고) |
| 파일 하나 | `사무실-3D-조명제어.html` 내려받아 더블클릭 (인터넷 불필요) |

권장 브라우저: Chrome, Edge, Safari 최신 버전. WebGL이 필요합니다.

## 앱으로 쓰기 — 데스크탑 · 스마트폰

브라우저 탭이 아니라 **독립된 창**으로 띄울 수 있습니다. 내려받을 설치 파일은 없습니다.
웹 주소를 연 다음 설치를 누르면 그대로 앱이 됩니다.

| 기기 | 설치 방법 |
|---|---|
| 데스크탑 (Chrome·Edge) | 주소창 오른쪽 설치 아이콘, 또는 왼쪽 사이드바 **앱 → 앱으로 설치** |
| 안드로이드 (Chrome) | 메뉴 → **앱 설치** |
| 아이폰 (Safari) | **공유 → 홈 화면에 추가** |

설치하면 작업표시줄이나 홈 화면에 아이콘이 생기고, 한 번 연 뒤에는 **인터넷이 끊겨도**
열립니다.

### 기기에 맞는 화면이 열립니다

같은 주소인데도 데스크탑에서는 사이드바가 있는 넓은 화면이, 휴대폰에서는 손가락에 맞춘
화면이 열립니다.

- **휴대폰 화면** — 3D가 화면을 꽉 채우고, 조작은 아래에서 올라오는 시트에 있습니다.
  시트 손잡이를 끌면 **접힘 / 반 / 전체** 3단계로 움직입니다. 세로 화면에서는 가로로 긴
  사무실이 작게 보이지 않도록 보는 방향을 바꿔 잡습니다.
- **직접 고르기** — 주소 뒤에 `?ui=desktop` 또는 `?ui=mobile` 을 붙이면 그 화면으로
  고정됩니다. 고른 값은 기억합니다.

## 구성

```
index.html      데스크탑 화면·스타일
mobile.html     스마트폰 화면 (app.js 를 그대로 쓰고 조작만 손가락에 맞춤)
mobile.js       바텀시트·탭 등 스마트폰 화면 전용 동작
app.js          3D 씬·조명 제어·상호작용
people.js       인물 피규어 (착석 근무 / 퇴근 보행)
data.js         사무실 치수·조명 배치·좌석 배치
figures.js      얼굴 사진 목록 (공개판은 비어 있음)
setup.js        좌석 이름·사진 설정
manifest.json   앱 이름·아이콘·시작 주소
sw.js           오프라인 캐시 (설치형일 때만 동작)
install.js      설치 단추·iOS 안내
lib/            three.js
```

빌드 도구도, 패키지 매니저도 쓰지 않습니다. 파일을 그대로 올리면 그게 배포본입니다.

## 조명 제어에 대해

공개판은 **시뮬레이션 전용**입니다. 화면 안에서만 켜지고 꺼집니다.
실제 조명 설비를 제어하는 기능은 사내 설비 주소가 필요해 이 배포본에 들어 있지 않습니다.
